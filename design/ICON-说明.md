# 图标制作说明

使用内置 imagegen 生成，未使用 API/CLI 回退。主题与确认原型一致：蓝色渐变、白色 WiFi、浅色文件夹、上下两支相反方向的蓝色箭头。系统负责外部圆角裁切。

最终原图：AppIcon-1024.png。Xcode 图标集在 iOS/LANDownloader/Assets.xcassets/AppIcon.appiconset，已包含 iPhone 和 App Store 所需尺寸。

生成提示词：
Create production iOS App icon, square 1024x1024 opaque PNG. Blue gradient edge-to-edge full square background cyan blue top to royal blue bottom (do NOT draw rounded outer corners, OS applies mask). Center a white/pale ice blue folder in bottom middle, three white WiFi arcs and small dot above the folder. On folder face exactly two blue horizontal arrows, upper points right and lower points left. Clean polished Apple-style dimensional but nearly flat, subtle folder shading, generous legible shapes for small size. No letters, text, numbers, border, mockup, outer shadow or padding. Reference concept: LAN file transfer blue WiFi plus folder with opposing arrows.
